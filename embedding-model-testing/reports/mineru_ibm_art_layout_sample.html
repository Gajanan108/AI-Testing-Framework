6. Scope limitations

The adapter tests layout-class presence only. It does not directly test object bounding-box quality, OCR recognition, the separate GGUF VLM, final Markdown output, or end-to-end MinerU document processing.
  • A top-class change is a robustness signal, not automatically a security vulnerability.
  • A single synthetic document image is a smoke test, not a representative benchmark.
  • Attack compatibility and successful execution must be recorded independently for each method.
  • Risk and severity require downstream impact and threat-model validation.
