# Security policy

## Scope

This repository contains assessment guidance, notebooks, and supporting artefacts for authorised AI/ML security testing. It is not an invitation to test systems without permission.

## Safe use

- Test only systems, models, datasets, and endpoints you own or are explicitly authorised to assess.
- Use isolated test environments and synthetic or approved data.
- Apply resource limits and stop conditions to avoid service disruption.
- Do not commit credentials, API keys, personal information, customer documents, private model weights, or confidential reports.
- Review notebook dependencies and downloaded model artefacts before execution.

## Reporting a vulnerability in this repository

Do not publish sensitive exploit details or secrets in a public issue. Use GitHub's private vulnerability reporting mechanism if enabled for this repository, or contact the repository maintainer through a private channel. Include the affected commit or file, impact, reproduction steps, and a safe evidence reference.

## Disclosure

Coordinate remediation and disclosure with the maintainer. Avoid accessing, modifying, or retaining data beyond what is necessary to demonstrate the issue.
